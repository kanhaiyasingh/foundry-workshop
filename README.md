# Microsoft Foundry: End-to-End Workshop

An end-to-end workshop for building enterprise AI applications and agents on
**Microsoft Foundry**, available as either **Python notebooks** or **C#/.NET 10**
console projects.

The journey starts with one Responses API call and ends with a grounded, tool-using,
evaluated, observable support agent. Both tracks cover all numbered labs M1-M15,
including M5b, and can use the same Foundry project and model deployments.

## Language tracks

Choose one track for the hands-on exercises:

| Choose | Best when you prefer | Required locally | Environment template |
|---|---|---|---|
| **Python notebooks** | Interactive cells, inline output, and Jupyter | Python 3.11-3.13 and a Jupyter client | `.env.example` |
| **C#/.NET** | Console applications, strongly typed code, and .NET tooling | .NET 10 SDK and VS Code or Visual Studio 2026 | `.env.csharp.example` |

Both tracks teach the same concepts and reach the same learning outcomes. Neither
track is a prerequisite for the other, and participants do not need to complete both.

- Python notebooks are under `docs/modules/*.ipynb`, generated by `scripts/gen_*.py`,
  with dependencies in `pyproject.toml`.
- C# console projects are under `labs/`, shared infrastructure is under
  `src/FoundryWorkshop.Shared/`, and participant guides are under
  `docs/modules/*.md`.

The tracks share core settings such as `PROJECT_ENDPOINT`, `CHAT_MODEL`,
`EMBEDDING_MODEL`, and `AZURE_SUBSCRIPTION_ID`, but each has its own environment
template and additional track-specific settings. Use only the template for your
chosen track.

Do not run both versions of a resource-creating lab against the same project at the
same time unless you use unique resource names.

## Architecture

```text
FoundryWorkshop.sln
├── src/FoundryWorkshop.Shared/       configuration, identity, REST, SSE, JSON
├── labs/01-first-inference/          one .NET 10 console project per lab
│   └── ...
├── labs/15-capstone/
├── docs/modules/*.md                 C# participant guides
├── docs/modules/*.ipynb              Python lab notebooks
├── scripts/                          Python notebook generators
└── pyproject.toml                    Python dependencies
```

Package versions are centrally pinned in `Directory.Packages.props`. The shared library
loads `.env` with DotNetEnv, uses `DefaultAzureCredential` by default
(`AzureCliCredential` with `AZURE_AUTH_MODE=cli`), and centralizes the Foundry project,
account, ARM, JSON, and SSE patterns.

## Start with Python

Choose this path if you selected **Python notebooks** above.

```bash
git clone https://github.com/kanhaiyasingh/foundry-workshop.git
cd foundry-workshop
python -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install -e .
python -m ipykernel install --user --name foundry-workshop \
  --display-name "Microsoft Foundry: End-to-End Workshop"
cp .env.example .env                   # Windows: Copy-Item .env.example .env
```

Open `.env` and replace the placeholder values for your subscription, Foundry project
endpoint, and model deployment names. Do not continue until those values are set.

```bash
az login
```

Complete the [Python setup guide](docs/setup.md), read the
[Python concepts](docs/concepts.md), then open
`docs/modules/01-first-inference.ipynb`.

## Start with C#/.NET

Choose this path if you selected **C#/.NET** above.

```powershell
git clone https://github.com/kanhaiyasingh/foundry-workshop.git
Set-Location foundry-workshop
Copy-Item .env.csharp.example .env
notepad .env
```

Replace the placeholder values for your subscription, Foundry project endpoint, and
model deployment names. Save `.env` before continuing.

```powershell
az login
dotnet restore .\FoundryWorkshop.sln
dotnet build .\FoundryWorkshop.sln --no-restore
dotnet run --project .\labs\01-first-inference -- --check
dotnet run --project .\labs\01-first-inference
```

On macOS/Linux, replace backslashes with `/` and use
`cp .env.csharp.example .env`. Read the complete
[C# setup guide](docs/csharp-setup.md), then the
[C# concepts](docs/csharp-concepts.md), before starting M1.
